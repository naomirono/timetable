A good timetable answers one question: where do I need to be right now, and what should I do next? Here is a simple way to build one that holds up for a whole term.

## 1. Start with fixed commitments

Add everything that cannot move: lessons, lectures, labs and tutorials. For each one, note the **room or venue** and the **lecturer or teacher**. When a room changes mid-term, this is the detail you will be glad to have in one place.

## 2. Make a separate timetable for each term

Your schedule changes every term or semester. Keep each one separate, so last term's classes never clutter this term's week. It also lets you look back at what you studied and when.

## 3. Mark classes that don't repeat weekly

Some classes run every second week. If your timetable treats them as weekly, you will turn up to an empty room or miss one entirely. Set these as biweekly from the start.

## 4. Add study blocks around your classes

Look for gaps of 45 minutes or more between classes and label a few of them as study time. Short, regular blocks work better than one long session at the weekend. If exams are coming up, our [exam revision plan](/blog/exam-revision-plan) shows how to use those blocks.

## 5. Add reminders you can trust

A timetable only helps if it reaches you at the right moment. Set a notification before each class starts, with enough time to walk or travel there.

## 6. Review it every Sunday

Spend five minutes checking the week ahead: new rooms, cancelled classes, deadlines. Small adjustments each week stop problems building up. Add this week's deadlines too, using the [homework planner tips](/blog/homework-planner-tips).

## Paper or app?

Paper is fine if your week never changes. If it does, an app is easier to edit, can remind you, and shows your timetable on your phone and tablet. [Class Timetable](/) does all of this on iPhone, iPad and Mac.
